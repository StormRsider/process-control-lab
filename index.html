Mathematical Theory & Control Principles

1. Introduction to Process Control

Process control is the engineering discipline that deals with maintaining output variables of a dynamic process within desired limits despite operational disturbances.

2. Open Loop vs. Closed Loop Control

In an open-loop system, control output is calculated without measuring the process variable (PV). In a closed-loop (feedback) system, the process variable is continuously measured by a sensor (Flow Transmitter FT) and compared against a target Set Point (SP).

3. Essential Control Loop Parameters

  • Set Point (SP): The desired target value for the process variable.
  • Process Variable (PV): The measured physical property (flow rate in L/min).
  • Controller Output (CO): The command signal (0–100%) sent to the control valve actuator.
  • Error (\(e(t)\)): \(e(t) = SP(t) - PV(t)\).

4. Ideal Parallel PID Controller Equation

The standard continuous time PID equation combining proportional, integral, and derivative actions is:

\[ u(t) = K_p \left[ e(t) + \frac{1}{T_i} \int_{0}^{t} e(\tau) d\tau + T_d \frac{de(t)}{dt} \right] \]

5. Role of Controller Gains

Proportional Gain (\(K_p\))

Produces output proportional to present error. Higher \(K_p\) speeds up response and reduces steady-state error, but leaves a permanent offset in P-only mode.

Integral Time (\(T_i\))

Accumulates past error over time. Integral action completely eliminates steady-state offset (\(e_{ss} = 0\)).

Derivative Time (\(T_d\))

Predicts future error based on current rate of change (\(\frac{de}{dt}\)). Provides anticipatory damping against rapid disturbances.

6. ON/OFF (Bang-Bang) Control & Differential Gap

ON/OFF controllers output either 100% or 0%. A hysteresis band (\(\Delta H\)) prevents rapid switching chatter:

\[ u(t) = \begin{cases} 100\% & \text{if } e(t) > +\frac{\Delta H}{2} \\ 0\% & \text{if } e(t) < -\frac{\Delta H}{2} \end{cases} \]
